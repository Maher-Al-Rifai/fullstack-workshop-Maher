# Pull-request evidence checklist

- [ ] Outcome and scope are stated.
- [ ] API/data compatibility is documented.
- [ ] Security and authorization impact is reviewed.
- [ ] Lowest useful tests protect the change.
- [ ] Migration upgrade/rollback path is documented where applicable.
- [ ] Accessibility, loading, error, and empty states are covered where applicable.
- [ ] Production images/configuration remain safe.
- [ ] Commands and evidence are attached.
- [ ] Learning log and module acceptance criteria are updated.
